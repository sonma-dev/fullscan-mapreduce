### BAT-001–003 — Classification, synchronization and backfill

1. **BAT-001:** consume CaseCreated case ID/revision in tenant scope; process NEW intake/business context and attach policy-aware labels, confidences and provenance. User correction requires reason code. Label domains, algorithm, attachment-completeness predicate, authorized correction interface and classification completion state remain BAT-OQ-006. Do not merge this event with RunRequested or assume run launch emits CaseCreated. [pp.12,87; `batch_functions:r1:c13:f1`, `batch_functions:r1:c139:f1`]
2. **BAT-002:** require complete provisioning and configured provider; inspect advertised list/fetch/delta cursor/ACL/delete support. Unsupported capabilities produce an explicit visible lower-trust warning, never silent assumptions or ACL bypass. Resolve workspace vault references; revoked queued credentials fail `CONNECTOR_REAUTH_REQUIRED` without token disclosure. Already-running revocation behavior remains open. [pp.27–28,78; `batch_functions:r1:c42:f1`, `batch_functions:r1:c42:f5`, `batch_functions:r1:c132:f2`]
3. Persist provider cursor/high-watermark/error ledger. Advance only after durable preceding ingestion outcomes. Partial batches retry safely. After bounded retries quarantine malformed items with reason/correlation/remediation; **remaining batch may proceed while ledger records the exception**. Continuation is permitted, not mandatory; quarantined item is not declared successful. Exact outcome/advancement predicate remains open. [pp.28–29; `batch_functions:r1:c43:f1`, `batch_functions:r1:c44:f6`]
4. Honor `Retry-After`, exponential backoff/jitter, workspace quotas and fair scheduling so a large tenant cannot starve smaller workspaces. No quota/batch/retry number is selected. [p.28; `batch_functions:r1:c44:f1`]
5. Source deletion creates tombstone/scheduled index removal. ACL changes invalidate affected cache before serving new results; revoked access applies before next retrieval even during cleanup. [pp.27–29; `batch_functions:r1:c41:f2`, `batch_functions:r1:c43:f4`, `batch_functions:r1:c43:f5`]
6. **BAT-003:** ingest historic sources in bounded windows using stable source IDs and per-batch reconciliation receipts. Determine search readiness from indexed coverage, **not merely queue emptiness**. Receipt schema, window bounds, coverage threshold, no-input and whole-run completion remain BAT-OQ-006. ### BAT-004–006 — Ingestion, index promotion and reconciliation

1. Admit only R1PDF/DOCX/HTML/UTF-8 text with MIME signature/extension agreement, configurable **25MB per file**, and decompression-bomb protection. MIME literals, MB convention and bomb/sandbox thresholds remain open. ZIP appears only as a hostile test fixture, not an admitted format.
2. Scan before parse. Disable macros; do not fetch embedded remote references. Unsafe attachments quarantine and never enter search.
3. Preserve PDF block page index/bbox, table rows/columns, heading/reading order for chunking. OCR is opt-in and provenance-marked; beyond-English OCR deferred.
4. Normalize transport artifacts without rewriting source claims. Content fingerprint plus pipeline version identifies immutable derivatives; revised processing may coexist side by side rather than overwrite history.
5. Store chunk URI/file hash/page/**optional** bbox. PDF block mandatory bbox does not make chunk bbox mandatory. Quality indicators include empty-page ratio, unknown-character ratio, table loss and language confidence. Low-quality authorized documents remain viewable but excluded from autonomous recommendations; low quality is not automatically unsafe quarantine. Thresholds/indexability/status mapping remain BAT-OQ-007.
6. `DocumentNormalized`, Ingestion version ID/source hash, builds index. Search rows contain tenant/workspace/document-version/chunk/language/classification, normalized keyword text and **1536-dimensional** embedding.
7. Rebuild a parallel index; switch versioned read alias atomically only after completeness and recall checks. Database remains authoritative. `SearchIndexCommitted`, Indexer generation/document revision, invalidates query cache. Promotion arbitration, thresholds and retired-generation policy remain open.
8. Failed index write **does not roll back accepted source metadata**. BAT-006 compares fingerprints/retries and repairs broken links from outbox. Apply permanent-error nonretry; no unrestricted repair loop is authorized. Reconciliation successful completion/receipt and selection remain open.

### BAT-007–009 — Grounded workflow, review expiry and publication

1. Create accepted run immediately; persist DAG plan revision before side effects. Depth **8**, maximum **16** tool invocations, explicit dependencies/replayable checkpoints. Persist each stage checkpoint before downstream dispatch.
2. Retrieve only current permitted evidence before releasing text to generation. Form lexical/normalized vector queries, bounded candidates, reciprocal rank fusion, deterministic rerank, document/source diversity and per-query token budget. Ranking never authorizes. Evidence includes chunk ID/source title/document revision/page anchor/ACL digest; citation identifiers are opaque/verified.
3. If confidence **OR** quality insufficient, return `NO_SUPPORTED_EVIDENCE`, never fabricated context. Clarification **OR** human routing remains unselected; missing citations produce needs-review **OR** unsupported under TST-009, not a chosen universal state.
4. Whitelist approved deployments by capability/region/handling/context/cost/evaluation. Reserve input/output tokens and track provider usage under workspace quota. Exhaustion is terminal for current run without automatic model/data-class change. Approved fallback requires equal-or-stronger handling and approved region/deployment; no restricted content in unapproved region on outage.
5. Compose fixed rules, signed workflow instruction, validated user input and delimited untrusted passages; strip evidence tool directives and record injection indicators. Model text never authorizes. Versioned JSON parsing has bounded retries; unknown fields, invalid citations/control injection produce `MODEL_OUTPUT_INVALID` and no publication.
6. Dispatch only pinned approved MCP schemas/validated arguments/scoped service credentials. External writes need separate capability, mutable calls idempotency and consequential human authorization. Discovery/A2A registration grants no permission; receivers may decline; denied actions cannot be replaced by equivalent tools.
7. Normalize/store policy sensitivity/action/evidence quality/model class/financial impact/confidence with rule version. Deterministic outcomes: `AUTO_ALLOW`, `HUMAN_REVIEW`, `REQUEST_MORE_EVIDENCE`, `DENY`; model tags cannot override. High-impact becomes review task, not autonomous mutation.
8. Select policy reviewer pool/minimum role/separation. Display exact candidate/citations/model-prompt version/policy reasons and inspectable anchored source. Required review fields gate Approve/Reject UI, not authorization. Record decision/actor/time/hash/rationale and optional annotations; changed/wrong-hash decisions stale-reject/audit with unchanged business state.
9. On configured-SLA expiry reassign **OR** escalate without approval. TST-010 requires escalation recorded. SLA/time basis/branch/recipients and no-expired-task result remain open. Overrides require elevated role/secondary reviewer/audited reason; denied rework is new run revision, never retroactive approval.
10. ApprovalDecisionRecorded **validates** publication. Recompute current authorization after permission changes and reject stale evidence. Required evidence/satisfied versioned policy/exact hash apply; unapproved high-risk cannot publish. Commit final response pointer and satisfied gate in the **same transaction**; replay cannot publish changed content under old approval.
