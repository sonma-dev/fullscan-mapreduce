## Method, evidence and exclusions

1. The class ledger was traversed in full; for every generated claim, original Markdown file/line/cell evidence was retained. Candidate PDF paragraphs and positive source quotes were retrieved from the original PDF, and PDF physical page numbers were stored. A source-side TP class reference was used as a *candidate bridge*, not proof that all additional qualifiers in its generated statement were verified.
2. Independent generated-only search looked for source-approved subclaims versus new definitive permissions. No safely established unsupported definitive implementation proposition was counted as `F_m` in this bounded review. This does **not** settle low-retrieval-similarity statements; 2,361 potential scope/eligibility cases are itemized for Phase 5, including some nondefinitive text that Phase 2 may have extracted too aggressively.
3. Each fixed source-negative counterfactual was checked through literal and semantic generated-corpus searches. A statement that prohibits the counterfactual is not an affirmative assertion. All 37 were therefore assigned TN in this best-effort judgment. Original source quotations and actual generated candidate locations are recorded.
4. The 1,024 source-positive canonical entries are exactly those from Phase 3; the 37 new finalized controls are appended. No FP-only unit was invented without a distinct, source-unentailed affirmative predicate. The same `U=R⊎N⊎F` and `P=A∪B∪F` were used for all four cells.
5. Raw occurrence/class duplicate counts are displayed as background only. Phase 5, not this turn, will perform the independent source-atomization, class-eligibility and semantic deduplication correction audit.

## Original PDF quotation provenance check

All 3,020 reverse-PDF evidence entries have a valid physical PDF page. 3,016 cited excerpts are located in the PDF text layer on the recorded page. The remaining 4 citations are p.8 figure-text phrases already inspected visually in Phase 1; these are not missing source pages. Locating a phrase does not alone prove complete logical entailment.

## Interpretation warning

The structural equality checks passed. Semantic certification **has not** passed: most reverse PDF matches are automated candidates, not independently established full logical entailments. No FP established in the bounded judgment is not verification that the corpus contains zero unsupported additions. Accordingly, all rates are labeled *provisional*. The metric is a source-specification evaluation, not application performance or a release gate.
