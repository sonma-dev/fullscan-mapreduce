## Reproducibility and limitations

1. The original user-supplied source-positive and negative-control files are not edited. This directory contains phase-corrected copies with explicit old/new ID mappings. All methods must use the same corrected R and N if later compared.
2. All PDFs are authoritative; Markdown explanation/status/proposal fields do not introduce new normative PDF requirements. Claims must be checked under inherited table/row context rather than isolated words.
3. One generated universal rule may cover multiple distinct source atoms; this adds canonical TP coverage but not generated occurrences or classes. Effective-universe Precision therefore differs from naive raw-class Precision.
4. Negative controls are 37 fixed PDF-grounded counterfactuals only. TN is not population-wide accuracy or the set of all unsupported features.
5. There remain 451 conservatively scored generated-only unsupported propositions; a failed bounded reciprocal search is not proof of source contradiction. There remain 378 FN entries, including partial and unresolved semantic evidence; the metrics could move in either direction.
6. The Phase 2 raw extraction contained classification leaks and missed some definitively worded original Markdown rows. Phase 5 explicitly corrected known entries and recalculated raw duplicates; complete unbounded semantic equivalence remains unverified.
7. Structural equations and file evidence locators were independently asserted within the phase, but mechanical literal presence is not independent full semantic certification. The final Phase 6 independent recomputation has not run.
8. All authored output files are English. No archive was produced.
