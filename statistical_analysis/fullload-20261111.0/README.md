# OrionDesk AI — Deliverables Archive (Original Phases 1–2 + Protocol v6.1 Phases 3–6)

This archive contains the available output artifacts from the original Phase 1 and Phase 2 execution, together with all extant authored output files from the v6.1 Phase 3–6 rerun, the v6.1 evaluation protocol, and its amendment diff.

## Layout

- `original_phase_01/`: original PDF source-atom inventory, fixed negative controls, source coverage and phase status.
- `original_phase_02/`: original generated-claim inventories, exclusion and line/cell coverage ledgers, duplicate-class ledger and phase status.
- `v6_1_phases_03_to_06/`: complete current v6.1 working/output directory, including the carried-forward Phase 1–2 ledgers required to reproduce the Phase 3–6 rerun, the Phase 3–6 deliverables, and the final recomputation script.
- `protocol/`: version 6.1 instructions and change diff.

## Scope and provenance

The original Phases 1 and 2 were completed before the protocol was revised to v6.1. The files in `original_phase_02/` are the latest available baseline copies; some underlying phase-2-derived ledgers were carried through subsequent baseline corrections and are not guaranteed to be immutable point-in-time snapshots of Phase 2 completion. The v6.1 directory contains the latest on-disk versions after Phase 6; earlier phase files may contain final corrections made in later phases.

This package does not include the uploaded source PDF and eight scored Markdown documents; it packages deliverables, not original inputs. The v6.1 evaluation status is `FINAL_BEST_EFFORT`, not full semantic certification. No historical v6.0 Phase 3–6 output files are added separately because the requested rerun is v6.1.
