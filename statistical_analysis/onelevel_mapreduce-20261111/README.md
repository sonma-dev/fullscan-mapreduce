# OrionDesk Evaluation Deliverables — Phases 1–6

This archive contains the original delivered artifacts from Phase 1, Phase 2, and all Phase 3–6 executions using evaluation protocol v6.1. The phase folder structure and filenames are preserved. Duplicate filenames in different phase directories are intentional because intermediate and final revisions are retained for reproducibility.

## Archive layout

- `phase_01/`: Phase 1 source-atom and PDF evidence artifacts, reused from fullload_cal.
- `phase_02/`: Phase 2 generated occurrences and semantic classes.
- `phase_03_v6.1/`: Phase 3 redo under protocol v6.1.
- `phase_04_v6.1/`: Phase 4 generated-validity and confusion-universe analysis.
- `phase_05_v6.1/`: Phase 5 correction, TP/FN and atomization audit, and duplicate metrics.
- `phase_06_v6.1/`: Phase 6 final ledgers, recomputation, diagnostics, and reporting.
- `protocol/`: The supplied protocol v6.1 used for the later phases.

## Scope

The older superseded Phase 3 evaluation under protocol v6.0 is intentionally excluded. Original scored input Markdown files and the PDF reference are not included because they are inputs rather than phase deliverables. The ZIP package itself is explicitly requested by the user and therefore overrides the original no-archive delivery convention.

## Interpretation

The Phase 6 metrics report a structurally reproducible best-effort result, not certified semantic completeness. See `phase_06_v6.1/08_coverage_and_limitations.md`.
