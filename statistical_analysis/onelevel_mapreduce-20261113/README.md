# OrionDesk AI — Phase 1–6 Evaluation Deliverables

This archive groups the completed evaluation deliverables by execution phase.

- `phase1/` — Source PDF requirements, bounded negative controls, source evidence and page coverage.
- `phase2/` — Generated Markdown requirement extraction, semantic classes, duplicate and exclusion ledgers.
- `phase3/` — PDF-to-generated semantic coverage, evidence bridges and false-negative challenge.
- `phase4/` — Generated-claim correctness and four-cell canonical confusion matrix.
- `phase5/` — Corrected judgments, TP and source atomization audits, duplicate metrics, and deltas.
- `phase6/` — Final independent recomputation, validation, coverage limitations, and reference inputs.

Files with the same basename in different phases are preserved independently to show the progression of judgments and corrections. The final corrected results are under `phase6/`. Internal temporary scratch files whose names start with `_` are excluded; input and deliverable files remain unchanged.
